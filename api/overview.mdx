# API Overview

The Cossistant API provides programmatic access to customer support conversations, visitor tracking, and real-time communication features. The API is built on a RESTful architecture with WebSocket support for real-time events.

## Base URL

```
https://api.cossistant.com/v1
```

## API Architecture

Cossistant provides three main API interfaces:

### REST API

HTTP-based API for creating and managing:
- **Conversations**: Create and retrieve customer conversations
- **Messages**: Send messages and timeline items
- **Visitors**: Track and identify website visitors
- **Feedback**: Collect and analyze customer feedback
- **Knowledge**: Manage knowledge base entries for AI agents

### WebSocket API

Real-time bidirectional communication for:
- Live conversation updates
- Typing indicators
- Presence tracking
- AI agent processing events
- Read receipts

### React Hooks

Pre-built React hooks for:
- Managing conversation state
- Sending messages with optimistic updates
- Real-time event subscriptions
- Visitor identification and metadata

## Rate Limits

API endpoints have different rate limits based on their purpose:

| Endpoint Type | Development | Production |
|--------------|-------------|------------|
| REST API | 300 req/min | 100 req/min |
| WebSocket | 30 conn/min | 10 conn/min |
| Auth | 30 req/min | 30 req/min |

See [Rate Limits](/api/rate-limits) for more information.

## Key Concepts

### Organizations & Websites

Every API request is scoped to:
- **Organization**: Your account
- **Website**: A specific project within your organization

### Visitors & Contacts

- **Visitor**: An anonymous browser session with device/location data
- **Contact**: An identified user with email, name, and metadata
- Use the `/contacts/identify` endpoint to link visitors to contacts

### Conversations & Timeline Items

- **Conversation**: A support thread between a visitor and your team
- **Timeline Item**: A message or event within a conversation
- Timeline items can be messages, events, or tool outputs

### Visibility Levels

- **Public**: Visible to both visitors and dashboard users
- **Private**: Only visible to dashboard users (internal notes)
