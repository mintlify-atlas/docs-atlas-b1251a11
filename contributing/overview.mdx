Thanks for your interest in contributing to Cossistant! This guide will help you understand our contribution process and how you can get involved.

## Current Status

Cossistant is in **early development phase**. We're focused on building a solid, secure, and scalable foundation before accepting external contributions.

<Note>
  We're **not accepting public pull requests yet** as the core architecture is still evolving rapidly. Once the foundation is stable, we'll open contributions with clear scopes, issues, and guidance.
</Note>

## Ways to Contribute Now

While we're not accepting PRs yet, there are several valuable ways you can contribute:

<Steps>
  <Step title="Star the Repository">
    Show your support by [starring the repo on GitHub](https://github.com/cossistant/cossistant). This helps us gauge community interest and motivates the team.
  </Step>
  
  <Step title="Report Bugs">
    Found a bug? [Open an issue](https://github.com/cossistant/cossistant/issues) with a detailed description, steps to reproduce, and your environment details.
  </Step>
  
  <Step title="Suggest Features">
    Have an idea? Share your feature suggestions and implementation ideas through GitHub issues. We read every submission.
  </Step>
  
  <Step title="Share Feedback">
    Help us improve by providing feedback on:
    - API design and developer experience
    - SDK structure and usability
    - Documentation clarity
    - Integration workflows
  </Step>
  
  <Step title="Join the Community">
    Connect with us on [Discord](https://discord.gg/vQkPjgvzcc) to discuss ideas, ask questions, and help shape the roadmap.
  </Step>
</Steps>

## When We Open Contributions

### Why We're Waiting

We want to respect your time and effort. Here's why we're holding off on PRs:

- **Rapid Evolution**: The core architecture changes week-to-week
- **Interface Stability**: Abstractions and APIs are still being refined
- **Avoid Waste**: We don't want your PRs rewritten or rejected due to architectural shifts

### Our Commitment

When we open contributions, we'll provide:

## Contribution Scope Areas

When we open contributions, these will be the key areas:

### Core SDK Development
- React hooks and primitives
- Next.js integrations
- TypeScript type definitions
- Performance optimizations

### Backend Services
- Hono API endpoints
- tRPC procedures
- Drizzle ORM schemas
- WebSocket handlers

### Developer Experience
- Documentation improvements
- Example applications
- Testing infrastructure
- Build tooling

### Community
- Issue triage and support
- Translation and localization
- Content creation and tutorials
