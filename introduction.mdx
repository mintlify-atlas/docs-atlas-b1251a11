## What is Cossistant?

Cossistant is an open-source customer support platform built specifically for developers and startups. It provides a complete support infrastructure with AI-powered agents, real-time messaging, and a flexible React SDK that integrates seamlessly into your application.

## Tech Stack

Cossistant is built with cutting-edge technologies:

- **Frontend**: React 19, Next.js 16, TypeScript
- **Backend**: Hono, tRPC, Drizzle ORM
- **Database**: PostgreSQL
- **Real-time**: WebSockets, Redis
- **Authentication**: Better Auth
- **AI**: OpenAI, OpenRouter integration
- **Infrastructure**: Docker, Bun runtime

## Get Started

<Steps>
  <Step title="Install the SDK">
    Add the Cossistant React SDK to your project
    
    <CodeGroup>
    ```bash npm
    npm install @cossistant/react
    ```
    
    ```bash yarn
    yarn add @cossistant/react
    ```
    
    ```bash pnpm
    pnpm add @cossistant/react
    ```
    
    ```bash bun
    bun add @cossistant/react
    ```
    </CodeGroup>
  </Step>
  
  <Step title="Configure your provider">
    Wrap your app with the SupportProvider component
    
    ```tsx
    import { SupportProvider, Support } from "@cossistant/react";
    import "@cossistant/react/styles.css";
    
    export function App() {
      return (
        <SupportProvider>
          <Support />
        </SupportProvider>
      );
    }
    ```
  </Step>
  
  <Step title="Start building">
    Customize the widget, identify visitors, and configure AI agents
  </Step>
</Steps>
