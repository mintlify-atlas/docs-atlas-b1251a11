## Overview

Cossistant uses environment variables for all configuration. Copy `.env.example` to `.env` and configure the values for your deployment.

<Warning>
  **Security**: Never commit `.env` files to version control. Always use strong, randomly generated secrets in production.
</Warning>

## Quick Setup

Generate secure secrets:

```bash
# Generate a random secret
openssl rand -base64 32

# Generate multiple secrets
for i in {1..3}; do openssl rand -base64 32; done
```

## Core Configuration

### Application

<ParamField path="NODE_ENV" type="string" default="development">
  Environment mode. Set to `production` for production deployments.
  
  **Values**: `development` | `production` | `test`
</ParamField>

<ParamField path="PORT" type="number" default="8787">
  Port for the API server to listen on.
  
  ```bash
  PORT=8787
  ```
</ParamField>

<ParamField path="PUBLIC_APP_URL" type="string" required>
  Public URL where your frontend application is hosted. Used for CORS, redirects, and generating links.
  
  ```bash
  PUBLIC_APP_URL=https://app.yourdomain.com
  ```
</ParamField>

## Database Configuration

<ParamField path="DATABASE_HOST" type="string" required>
  PostgreSQL server hostname or IP address.
  
  ```bash
  DATABASE_HOST=localhost
  # or
  DATABASE_HOST=db.example.com
  ```
</ParamField>

<ParamField path="DATABASE_PORT" type="number" default="5432" required>
  PostgreSQL server port.
  
  ```bash
  DATABASE_PORT=5432
  ```
</ParamField>

<ParamField path="DATABASE_USERNAME" type="string" required>
  PostgreSQL username.
  
  ```bash
  DATABASE_USERNAME=postgres
  ```
</ParamField>

<ParamField path="DATABASE_PASSWORD" type="string" required>
  PostgreSQL password.
  
  ```bash
  DATABASE_PASSWORD=your_secure_password
  ```
</ParamField>

<ParamField path="DATABASE_NAME" type="string" required>
  PostgreSQL database name.
  
  ```bash
  DATABASE_NAME=cossistant
  ```
</ParamField>

<Info>
  **SSL Connections**: In production, the API automatically enables SSL for database connections with `rejectUnauthorized: false`. For stricter SSL validation, modify the connection configuration in `apps/api/src/db/index.ts`.
</Info>

## Redis Configuration

<ParamField path="REDIS_URL" type="string" required>
  Redis connection URL. Supports standard Redis URL format.
  
  ```bash
  # Local Redis
  REDIS_URL=redis://localhost:6379
  
  # Redis with password
  REDIS_URL=redis://:password@localhost:6379
  
  # Redis with database number
  REDIS_URL=redis://localhost:6379/0
  
  # Upstash Redis
  REDIS_URL=rediss://default:password@region.upstash.io:6379
  ```
</ParamField>

## Authentication

### Better Auth

<ParamField path="BETTER_AUTH_URL" type="string" required>
  Base URL for Better Auth authentication service. Should match your API URL.
  
  ```bash
  BETTER_AUTH_URL=http://localhost:8787
  # or in production
  BETTER_AUTH_URL=https://api.yourdomain.com
  ```
</ParamField>

<ParamField path="BETTER_AUTH_SECRET" type="string" required>
  Secret key for signing authentication tokens. Generate with `openssl rand -base64 32`.
  
  ```bash
  BETTER_AUTH_SECRET=your_random_secret_here
  ```
</ParamField>

### API Keys

<ParamField path="API_KEY_SECRET" type="string" required>
  Secret used for signing and validating API keys. Generate with `openssl rand -base64 32`.
  
  ```bash
  API_KEY_SECRET=your_random_secret_here
  ```
</ParamField>

### OAuth Providers (Optional)

<ParamField path="GOOGLE_CLIENT_ID" type="string" optional>
  Google OAuth 2.0 client ID. Get from [Google Cloud Console](https://console.cloud.google.com/).
  
  ```bash
  GOOGLE_CLIENT_ID=your-client-id.apps.googleusercontent.com
  ```
</ParamField>

<ParamField path="GOOGLE_CLIENT_SECRET" type="string" optional>
  Google OAuth 2.0 client secret.
  
  ```bash
  GOOGLE_CLIENT_SECRET=your_google_client_secret
  ```
</ParamField>

<ParamField path="GITHUB_CLIENT_ID" type="string" optional>
  GitHub OAuth App client ID. Create at [GitHub Developer Settings](https://github.com/settings/developers).
  
  ```bash
  GITHUB_CLIENT_ID=your_github_client_id
  ```
</ParamField>

<ParamField path="GITHUB_CLIENT_SECRET" type="string" optional>
  GitHub OAuth App client secret.
  
  ```bash
  GITHUB_CLIENT_SECRET=your_github_client_secret
  ```
</ParamField>

## File Storage (S3)

<ParamField path="S3_BUCKET_NAME" type="string" required>
  S3 bucket name for storing uploaded files.
  
  ```bash
  S3_BUCKET_NAME=cossistant-uploads
  ```
</ParamField>

<ParamField path="S3_REGION" type="string" required>
  AWS region for S3 bucket.
  
  ```bash
  S3_REGION=us-east-1
  ```
</ParamField>

<ParamField path="S3_ACCESS_KEY_ID" type="string" required>
  AWS access key ID with S3 permissions.
  
  ```bash
  S3_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
  ```
</ParamField>

<ParamField path="S3_SECRET_ACCESS_KEY" type="string" required>
  AWS secret access key.
  
  ```bash
  S3_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
  ```
</ParamField>

<ParamField path="S3_ENDPOINT" type="string" optional>
  Custom S3 endpoint for S3-compatible services (Cloudflare R2, MinIO, DigitalOcean Spaces).
  
  ```bash
  # Cloudflare R2
  S3_ENDPOINT=https://account-id.r2.cloudflarestorage.com
  
  # MinIO
  S3_ENDPOINT=https://minio.yourdomain.com
  
  # DigitalOcean Spaces
  S3_ENDPOINT=https://nyc3.digitaloceanspaces.com
  ```
</ParamField>

<ParamField path="S3_FORCE_PATH_STYLE" type="boolean" default="false">
  Use path-style URLs instead of virtual-hosted style. Required for some S3-compatible services.
  
  ```bash
  S3_FORCE_PATH_STYLE=true
  ```
</ParamField>

<ParamField path="S3_SIGNED_URL_EXPIRATION_SECONDS" type="number" default="900">
  Expiration time for pre-signed upload URLs in seconds (default: 15 minutes).
  
  ```bash
  S3_SIGNED_URL_EXPIRATION_SECONDS=900
  ```
</ParamField>

<ParamField path="S3_PUBLIC_BASE_URL" type="string" optional>
  Public base URL for accessing uploaded files. Use if files are publicly accessible.
  
  ```bash
  S3_PUBLIC_BASE_URL=https://uploads.yourdomain.com
  ```
</ParamField>

<ParamField path="S3_CDN_BASE_URL" type="string" optional>
  CDN base URL for serving files through a CDN (CloudFront, CloudFlare, etc.).
  
  ```bash
  S3_CDN_BASE_URL=https://cdn.yourdomain.com
  ```
</ParamField>

## Queue Service (QStash)

<ParamField path="QSTASH_URL" type="string" default="https://qstash.upstash.io/v2">
  Upstash QStash API endpoint.
  
  ```bash
  QSTASH_URL=https://qstash.upstash.io/v2
  ```
</ParamField>

<ParamField path="QSTASH_TOKEN" type="string" required>
  Upstash QStash authentication token. Get from [Upstash Console](https://console.upstash.com/qstash).
  
  ```bash
  QSTASH_TOKEN=your_qstash_token
  ```
</ParamField>

<ParamField path="QSTASH_CURRENT_SIGNING_KEY" type="string" required>
  Current signing key for verifying QStash webhook requests.
  
  ```bash
  QSTASH_CURRENT_SIGNING_KEY=your_current_signing_key
  ```
</ParamField>

<ParamField path="QSTASH_NEXT_SIGNING_KEY" type="string" required>
  Next signing key for key rotation support.
  
  ```bash
  QSTASH_NEXT_SIGNING_KEY=your_next_signing_key
  ```
</ParamField>

<Info>
  **Development Mode**: QStash is optional for development. Use `@upstash/qstash-cli dev` for local testing.
</Info>

## AI Services (Optional)

### OpenRouter

<ParamField path="OPENROUTER_API_KEY" type="string" optional>
  OpenRouter API key for AI agent functionality. Get from [OpenRouter](https://openrouter.ai/).
  
  ```bash
  OPENROUTER_API_KEY=sk-or-v1-...
  ```
</ParamField>

<ParamField path="OPENROUTER_EMBEDDING_MODEL" type="string" default="openai/text-embedding-3-small">
  Model to use for generating embeddings.
  
  ```bash
  OPENROUTER_EMBEDDING_MODEL=openai/text-embedding-3-small
  ```
</ParamField>

### RAG Service

<ParamField path="RAG_SERVICE_URL" type="string" default="http://localhost:8082">
  URL for the RAG (Retrieval-Augmented Generation) service used for document chunking.
  
  ```bash
  RAG_SERVICE_URL=http://localhost:8082
  ```
</ParamField>

### Firecrawl

<ParamField path="FIRECRAWL_API_KEY" type="string" optional>
  Firecrawl API key for web scraping capabilities. Get from [Firecrawl](https://firecrawl.dev/).
  
  ```bash
  FIRECRAWL_API_KEY=fc-...
  ```
</ParamField>

### AI Agent Configuration

<ParamField path="AI_AGENT_DEEP_TRACE_ENABLED" type="boolean" default="false">
  Enable detailed tracing for AI agent operations (useful for debugging).
  
  ```bash
  AI_AGENT_DEEP_TRACE_ENABLED=true
  ```
</ParamField>

<ParamField path="AI_AGENT_TRACE_HEARTBEAT_MS" type="number" default="2000">
  Heartbeat interval for AI agent trace updates in milliseconds.
  
  ```bash
  AI_AGENT_TRACE_HEARTBEAT_MS=2000
  ```
</ParamField>

<ParamField path="AI_AGENT_TRACE_PAYLOAD_MODE" type="string" default="sanitized">
  How to handle trace payloads. Use `raw` for full payloads (dev) or `sanitized` for production.
  
  **Values**: `raw` | `sanitized`
  
  ```bash
  AI_AGENT_TRACE_PAYLOAD_MODE=sanitized
  ```
</ParamField>

<ParamField path="AI_AGENT_ROGUE_WINDOW_SECONDS" type="number" default="60">
  Time window for detecting rogue AI agent behavior.
  
  ```bash
  AI_AGENT_ROGUE_WINDOW_SECONDS=60
  ```
</ParamField>

<ParamField path="AI_AGENT_ROGUE_MAX_PUBLIC_MESSAGES" type="number" default="8">
  Maximum public messages allowed before rate limiting AI agents.
  
  ```bash
  AI_AGENT_ROGUE_MAX_PUBLIC_MESSAGES=8
  ```
</ParamField>

<ParamField path="AI_AGENT_ROGUE_PAUSE_MINUTES" type="number" default="15">
  How long to pause rogue AI agents in minutes.
  
  ```bash
  AI_AGENT_ROGUE_PAUSE_MINUTES=15
  ```
</ParamField>

## Example Configuration Files

### Minimal Development Setup

```bash .env.development
# Core
NODE_ENV=development
PORT=8787
PUBLIC_APP_URL=http://localhost:3000

# Database
DATABASE_HOST=localhost
DATABASE_PORT=5432
DATABASE_USERNAME=postgres
DATABASE_PASSWORD=postgres
DATABASE_NAME=cossistant

# Redis
REDIS_URL=redis://localhost:6379

# Authentication
BETTER_AUTH_URL=http://localhost:8787
BETTER_AUTH_SECRET=dev_secret_change_in_production
API_KEY_SECRET=dev_api_secret_change_in_production

# Email (Resend)
RESEND_API_KEY=re_your_api_key

# S3 Storage
S3_BUCKET_NAME=cossistant-dev
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=your_access_key
S3_SECRET_ACCESS_KEY=your_secret_key

# QStash (optional in dev)
QSTASH_TOKEN=
QSTASH_CURRENT_SIGNING_KEY=
QSTASH_NEXT_SIGNING_KEY=
```

### Production Setup

```bash .env.production
# Core
NODE_ENV=production
PORT=8787
PUBLIC_APP_URL=https://app.yourdomain.com

# Database (use managed service)
DATABASE_HOST=db.your-cloud.com
DATABASE_PORT=5432
DATABASE_USERNAME=cossistant_user
DATABASE_PASSWORD=<strong-password>
DATABASE_NAME=cossistant_prod

# Redis (use managed service)
REDIS_URL=rediss://default:<password>@redis.your-cloud.com:6379

# Authentication (generate with openssl rand -base64 32)
BETTER_AUTH_URL=https://api.yourdomain.com
BETTER_AUTH_SECRET=<random-32-byte-secret>
API_KEY_SECRET=<random-32-byte-secret>

# OAuth
GOOGLE_CLIENT_ID=your-app.apps.googleusercontent.com
GOOGLE_CLIENT_SECRET=<google-secret>
GITHUB_CLIENT_ID=<github-client-id>
GITHUB_CLIENT_SECRET=<github-secret>

# Email
RESEND_API_KEY=re_<production-key>
RESEND_AUDIENCE_ID=<audience-id>

# S3 Storage (production bucket)
S3_BUCKET_NAME=cossistant-prod-uploads
S3_REGION=us-east-1
S3_ACCESS_KEY_ID=<access-key>
S3_SECRET_ACCESS_KEY=<secret-key>
S3_CDN_BASE_URL=https://cdn.yourdomain.com

# QStash
QSTASH_TOKEN=<qstash-token>
QSTASH_CURRENT_SIGNING_KEY=<current-key>
QSTASH_NEXT_SIGNING_KEY=<next-key>

# AI (if enabled)
OPENROUTER_API_KEY=sk-or-v1-<key>

# Monitoring
AI_AGENT_DEEP_TRACE_ENABLED=false
AI_AGENT_TRACE_PAYLOAD_MODE=sanitized
```

## Validation

Verify your configuration:

```bash
# Check required environment variables are set
bun run apps/api/src/env.ts

# Test database connection
psql "postgresql://${DATABASE_USERNAME}:${DATABASE_PASSWORD}@${DATABASE_HOST}:${DATABASE_PORT}/${DATABASE_NAME}" -c "SELECT version();"

# Test Redis connection
redis-cli -u "${REDIS_URL}" ping
```

<Warning>
  **Missing Variables**: The API will warn about missing required environment variables on startup. In production builds on Vercel, some warnings are suppressed as certain variables may not be needed at build time.
</Warning>
